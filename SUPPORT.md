# Support

Use the channel that matches the request:

- Questions and usage help: [GitHub Discussions](https://github.com/ajayasai/OpenCollate/discussions)
- Reproducible defects: [bug report](https://github.com/ajayasai/OpenCollate/issues/new?template=bug.yml)
- Suspected false result: [false-positive/negative report](https://github.com/ajayasai/OpenCollate/issues/new?template=false-positive.yml)
- Format support: [format request](https://github.com/ajayasai/OpenCollate/issues/new?template=format-request.yml)
- Security vulnerability: follow [SECURITY.md](SECURITY.md)

OpenCollate is community-supported. There is no guaranteed response time or commercial support
commitment.

Before asking for help, run:

```console
opencollate --version
opencollate capabilities
```

Include the version, platform, Python version, command, diagnostic code, and a minimal synthetic
reproduction. Never post proprietary or confidential collateral.
